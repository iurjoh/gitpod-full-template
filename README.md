## Architecture and design

index.html loads Bootstrap 4.6.2, Font Awesome 4.7.0 and local CSS. Header columns, section and footer are mostly empty. assets/css/style.css supplies a Rosie image background, 360px minimum height and font/transition styles. That sample asset is course material, not the owner's verified portrait. Workspace configuration is historical, not proof of current Gitpod compatibility.
